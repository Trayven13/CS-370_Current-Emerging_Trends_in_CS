# CS-370_Current-Emerging_Trends_in_CS

What do computer scientists do and why does it matter?
  Computer scientists develop solutions to problems using technology. In this project, we used neural networks and deep Q-learning to train an agent to solve a maze.
  
How do I approach a problem as a computer scientist?
  I first start by understanding the problem. I then identify possible solutions and develop a plan. I then test and make adjustments as needed. In this project, I used reinforcement learning to train the pirate agent and monitored its progress to see if the algorithm was working.

What are my ethical responsibilities?
  My ethical responsibilities include protecting user information, developing reliable systems, and considering how my work could affect users and organizations. While our pirate maze was a simple project, the same AI technology can be used in real-world applications where security and fairness are important.
